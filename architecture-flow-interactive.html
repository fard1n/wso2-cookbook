Role Responsibilities & Hard Rules

  • Front door for all public traffic (*.parspc.ir).
  • Terminates lab wildcard TLS (parspc-lab.crt).
  • Separate upstreams for Portals (:9443 sticky) vs APIs (:8243 stateless).
  • Trusts APIM nodes via parspc-tls.cer with proxy_ssl_verify on.
Configuration Snippet /etc/nginx/sites-available/wso-apim 
upstream apim_portals {
    ip_hash;
    server wso-apim-1:9443 max_fails=3 fail_timeout=10s;
    server wso-apim-2:9443 max_fails=3 fail_timeout=10s;
}

upstream apim_gw {
    server wso-apim-1:8243;
    server wso-apim-2:8243;
}

⚠️ Keystore Law (Rule #1)

NEVER remake newkeystore.jks. It encrypts live secrets stored in PostgreSQL. Both APIM-1 and APIM-2 must share this exact file. Remaking it invalidates all database credentials.

🏷️ Guest Hostnames (Rule #2)

Use exact names: wso-apim-1, wso-apim-2, wso-apim-lb, wso-apim-database. No .local. No parspc on the guest name. After a clone, rewrite hostnamectl and 127.0.1.1 immediately!

🌐 DNS & Single-Label (Rule #3)

Ubuntu systemd-resolved drops single-label short names (no dots) by default. Solved with:
ResolveUnicastSingleLabel=yes in /etc/systemd/resolved.conf.d/single-label.conf.

⚡ Event Hub Active Mesh (Rule #4)

Event Hub connects via SAN names (ssl://wso-apim-1:9711 and ssl://wso-apim-2:9711). Never use raw IPs because Java TLS handshakes check SANs. Event Hub eliminates the need for shared NFS storage!

💾 Database Dual Schemas (Rule #5)

PostgreSQL 18 hosts two distinct schemas: WSO2AM_DB (APIs, tokens, apps) and WSO2SHARED_DB (users, roles, permissions). Never create a 3rd analytics DB (analytics uses OpenSearch).
